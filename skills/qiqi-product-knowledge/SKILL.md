## 强制检索流程

1. **判断是否该查**（见「事实边界」）。
2. **主通道：`entry_list_children`（零依赖、最稳）**
   - 传模块文件夹 entry_id（见下表），即可拿到 `[{id, name}]`，
     **name 形如 `[EX-002] 功能：员工借款单`** —— 条目码与 entry_id 一次到手。
   - 无需先查登记册，也不受任何检索质量影响。
3. **取正文**：`entry_describe_ai_parse_content(entry_id)`（全文）
   或 `block_fetch_page(entry_id, render_mode="mdx")`（拿带 `data-id` 的结构，用于小节级引用）。
4. **辅助通道（按需）**：
   - `search_kb_search`（关键词）—— 命中标题即含条目码，适合只知功能名时。
   - `[IDX-00.2-<域码>]` 模块索引页 —— `block_fetch_page(markdown)` 可读出每条的
     能力域 / 来源轴 / 生命周期 / entry_id（供按轴筛选）。
   - `search_kb_embedding_search`（语义）—— 只用于「发现线索」，**不能作为引用依据**。
5. **未命中时**：判「知识库未覆盖」并引 `[GOV-03]`。

> ⚠️ **登记册（智能表格）经 MCP 读不到字段值** —— 实测 `smartsheet_list_records` /
   `smartsheet_describe_record` / 按视图 / `lexiang_fetch(record)` 四条路径**均只返回 record_id**。
   因此登记册**不是**可靠的机器入口；请用 §2 的 `entry_list_children` 或 §4 的索引页。

## 事实边界（铁律）

- 知识库只给**产品定义**，**不证明**当前租户已启用该功能、有权限或存在相应数据。
  客户实际对象／字段／枚举／权限／取数 → 走运行时核实（`qiqi-cli`、`qiqi-business-foundations`），**不得用知识库代替**。
- 未命中登记册且语义检索无果 → 写「**知识库未覆盖**」并引 `[GOV-03]`；**禁止臆测产品行为**。
- **检索无果 ≠ 能力不存在**：部分能力只在客开内部文档记载（标 🗂️），判定存在性时须把
  客开内部文档作为**第三类来源**考虑 → 见 `[GOV-01]` §三。
- **时效**：内容覆盖至 **2026-09-14**；帮助文档（S1）与迭代说明（S2）冲突时取**发布日期较晚者**。
- **待复核**：条目「最近复核」过期或生命周期 = `待核实` 时，结论须标注「复核已过期」。

## 写作与写入

- **写入前四步**（缺一不可）：检索去重 → 定位落点 → 成稿（带来源轴 + 日期）→ **展示待写内容取得用户确认**。
- **写入前必须读页面正文，不得只凭本技能摘要动手**（2026-10-21 实测教训）：
  - 先读 `[GOV-04]` 撰写、评审与引用规范 —— 管「怎么写、怎么引、写哪一层」；
  - 再读 `[GOV-06]` 平台能力与免费版约束 —— 管「平台写入约束、报错码、读写坑位」，且该页声明自己是**平台约束的唯一登记处**。
  - 只加载本技能而没读这两页正文，会漏掉其中已有的硬规则（星号转义、反斜杠禁令、表行数上限、`update_text` 载荷形状等）。
- **落点判定口径**（一事实一落点的具体化）：
  - **载荷 / 参数 / 报错码 / 能力可用性** → `[GOV-06]`
  - **渲染转义 / 条目模板 / 引用格式 / 索引规则** → `[GOV-04]`
  - 跨页**只留一行指针，禁止复制正文**（双副本必然漂移）。
- Agent **只提案**（存草稿），**发布权在人**：贡献者存草稿 → 域负责人评审 → 主编发布。
- 乐享是**共享空间**，**未经用户确认不得写入**。
- 一事实一落点，**禁止为同一功能多点建档**。
- **块级写入现状坑位速查**（详见 `[GOV-06]` §6.1～§6.3）：
  - 带样式的文本更新用 `update_text_elements: {elements: [...]}`；改用 `update_text` 时 `elements` 与 `style` 必须**同级直挂**，多套一层 `text` 会**返回 success 但静默不落库**。
  - 复核写入结果**只认 `block_fetch_page`**：`edited_at` 不随块级写入推进、`entry_describe_ai_parse_content` 返回旧快照、`block_describe_block` 对已删块仍回旧内容。

> ⚠️ **删除高危**：MCP 无批量删除条目能力，仅 `entry_delete_entry`（无二次确认）；
> 该工具不在 `search_tools` 清单中，**禁止据 `search_tools` 无结果断言其不存在**，也禁止用于探测性调用。
